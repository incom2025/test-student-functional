## Генератори

Генератор — це спеціальний вид ітератора, який повертає значення
поступово, у міру необхідності.

Для створення генератора використовується оператор:

`yield`

На відміну від `return`, оператор `yield` не завершує виконання
функції остаточно. Стан функції зберігається, а під час наступного
звернення виконання продовжується з місця попередньої зупинки.

## Lazy evaluation

Lazy evaluation (ліниве обчислення) означає, що значення
обчислюються тільки тоді, коли вони реально потрібні.

Генератор не створює всю послідовність наперед.

Наприклад, нескінченна послідовність чисел Фібоначчі може
генеруватися поступово:

```python
def fib_stream():
    a, b = 0, 1

    while True:
        yield a
        a, b = b, a + b
