# Лабораторна робота №7

## Тема

Композиція функцій, функціональні конвеєри та функціональні засоби Python.

## Мета роботи

Навчитися будувати функціональні конвеєри обробки даних, використовувати
композицію функцій, функції вищого порядку та стандартні функціональні
можливості Python.

## Варіант

Варіант №1.

## Реалізація

У лабораторній роботі реалізовано:

- завантаження даних із JSON;
- завантаження даних із CSV;
- функціональний pipeline;
- композицію функцій;
- перетворення даних студентів;
- ранжування студентів;
- клас `StudentRank`;
- порівняння об'єктів за допомогою `total_ordering`;
- автоматизовані тести.
