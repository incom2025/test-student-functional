# Лабораторна робота №6

## Тема

Замикання, декоратори та керування станом у функційному програмуванні Python.

## Мета роботи

Дослідити механізм замикань у Python, використання `nonlocal`,
функцій вищого порядку та декораторів. Навчитися створювати
параметризовані декоратори, реалізовувати кешування результатів
і зберігати стан без використання глобальних змінних.

## Реалізація

У лабораторній роботі реалізовано:

- замикання (`closure`);
- збереження стану всередині функції;
- використання `nonlocal`;
- лічильник на основі замикання;
- параметризований множник;
- декоратор вимірювання часу виконання;
- `functools.wraps`;
- параметризований декоратор;
- TTL-кешування;
- очищення кешу;
- інвалідацію окремого значення кешу;
- dependency injection через декоратор;
- анотації типів;
- `ParamSpec` та `TypeVar`;
- автоматизовані тести.
